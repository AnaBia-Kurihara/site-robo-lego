ESPECIFICAÇÕES ROBÔ

Arma escolhida

A arma do robô foi desenvolvida para estourar o balão do adversário por meio de um mecanismo de impacto lateral. Ela consiste em
uma barra rígida acoplada a um sistema rotacional, capaz de realizar movimentos rápidos e controlados. Posicionada estrategicamente
nas laterais do robô, a arma aumenta a área de alcance e a eficiência dos ataques. O projeto também considera estabilidade,
resistência estrutural e boa distribuição de peso, garantindo desempenho consistente durante as competições.

Modo de funcionamento

O funcionamento é baseado em movimento rotacional controlado.
Etapas:

  1. O operador envia comando via controle.
  2. O microcontrolador envia sinal PWM para o servo.
  3. O servo gira rapidamente em determinado ângulo.
  4. A barra de aço acompanha o movimento e atinge o oponente.
  5. O servo retorna para posição inicial ou continua rotacionando.

Golpe Controlado:

  • Servo gira apenas quando acionado. Economiza energia. Mais controle estratégico.

Aplicada no Robô

A arma é aplicada nas laterais do robô, sendo composta por:

  1. Um servo motor de alto torque fixado na estrutura interna.
  2. Uma barra de aço acoplada rigidamente ao eixo do servo.
  3. Sistema de fixação reforçado para suportar impacto e vibração.
  4. A barra fica posicionada de forma que, ao girar, ela projeta golpes para a parte frontal do robô.

    5. Estruturalmente

    • O servo é preso em uma base rígida (chassi interno).
    • A barra atravessa uma abertura lateral.
    • O centro de rotação fica alinhado com a estrutura para evitar empenamento.
    • Se forem duas armas (uma de cada lado), elas giram simultaneamente.
